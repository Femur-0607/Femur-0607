## About Me

I am preparing for a career as a game client programmer, with experience in Unity C# and Unreal Engine C++ projects.

My main interest is connecting gameplay systems into a stable player experience: input, UI, combat, wave flow, save data, object pooling, grid logic, and team-ready feature structure.

I like solving bugs by reproducing the issue, identifying the cause, changing the structure, and verifying the result. I also value documentation and communication so that teammates can work from the same standard.

## Featured Projects

### MiniDriller

Unreal Engine 5 C++ grid-based mining action project.

- Implemented logical grid management with `TMap<FIntPoint, ABlock*>`.
- Built block object pooling and state reset flow.
- Implemented flood fill based Match-4 chain clearing.
- Solved overlapping and floating block issues by separating logical grid coordinates from visual position.
- Managed score, oxygen, depth, level, and save flow through game status systems.

[Repository](https://github.com/Femur-0607/MiniDriller-Portfolio) / [Demo Video](https://youtu.be/efCUcJviVkE)

### Castle Guardian VR

Unity C# VR defense game project.

- Implemented VR bow aiming, projectile firing, and trajectory feedback.
- Built wave, spawn, formation, tower, enemy, projectile, and event systems.
- Used ScriptableObject data separation for enemies, towers, projectiles, and waves.
- Applied object pooling for enemies, projectiles, particles, and audio sources.

[Repository](https://github.com/Femur-0607/Castle-Guardian-VR-Portfolio) / [Demo Video](https://youtu.be/KxXcOsSTjww)

### Project TownLife

Unity 2D top-down shop management team project.

- Working on a core loop: gather, craft, sell, grow, save, next day.
- Organized feature scope, team rules, Git branch strategy, and implementation standards.
- Focused on data-driven structure, event channels, save data, UI flow, and team collaboration.

[Repository](https://github.com/Femur-0607/ProjectTownLife)

### DunLegacy
